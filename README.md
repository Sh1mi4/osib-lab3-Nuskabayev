# Репозиторий документации СМИБ

Репозиторий предназначен для хранения и контроля изменений
документированной информации системы менеджмента информационной безопасности.

## Структура

- 01-politika — политика информационной безопасности
- 02-chastnye-politiki — частные политики
- 03-procedury — процедуры и регламенты
- 04-instrukcii — инструкции, шаблоны и чек-листы
- 05-zapisi — записи и формы

Все изменения документов фиксируются средствами Git.
